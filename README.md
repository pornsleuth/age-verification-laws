# Age verification laws for adult websites

Where the law requires adult websites to check that a visitor is 18 or over, by country and US state, with the law's name, the date it took effect and a source.

- **Live version, checked daily:** [pornsleuth.com/age-verification-laws](https://pornsleuth.com/age-verification-laws)
- **This file:** `age-verification-laws.csv`, a snapshot of the same table. The live page is always newer.

## Columns

| Column | Meaning |
|---|---|
| `place` | Country or US state |
| `country` | ISO 3166-1 code |
| `region` | US state code, empty for a country |
| `status` | Age check required · Law passed, not yet in force · Adult sites prohibited · No age-check law |
| `law` | The law's name or number |
| `effective_from` | Date it took effect (YYYY-MM-DD), if known |
| `source` | Official or industry source for the row |
| `verified` | `yes` once confirmed against an official source |
